# 06 · 并发读写与 Flush 交叉

顺序单测验证组件正确性；本小节验证引擎在多线程下的行为：

1. 多个写线程按 key 空间分区并发 `Put`  
2. 多个读线程在写过程中轮询 `Get`（允许暂时 NotFound，不允许读到错值）  
3. 小 `write_buffer_size` 下，写进行中后台 Flush 产生 SST  
4. 并发覆盖写 / 删除后再 Open 恢复  

```bash
./build/test_concurrent
```

当前实现用一把 DB 级互斥锁串行化 API；可观察的交叉主要来自「前台写 + 后台 Flush」并行推进，而不是无锁并行刷盘。
