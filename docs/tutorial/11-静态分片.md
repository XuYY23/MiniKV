# 11 · 静态分片

```text
Client Put/Get/Delete
  → ShardOf(key) = hash(key) % N
  → 该分片 Raft group 的 Leader
  → Propose → Apply → 该副本本地 LSM
```

- **每分片一组独立 Raft**（日志互不共享）  
- **不做**自动迁片 / 再均衡  
- `MemoryTransport` 用于确定性测试，`TcpRaftTransport` 用于跨进程节点连接

